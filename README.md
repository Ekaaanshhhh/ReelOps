# ReelOps

## Overview
ReelOps is an AI-powered content collaboration and automated publishing platform designed to streamline video content management across multiple platforms.

## Features
* Multi-channel collaboration
* Role-based access control
* AI metadata generation
* Channel chat
* Automation scheduling
* YouTube OAuth integration
* Automated YouTube publishing
* Execution logs
* OAuth revocation handling
* Atomic scheduler locking

## Tech Stack
### Frontend
* React
* Tailwind CSS
* Axios
* Socket.IO

### Backend
* Node.js
* Express.js

### Database
* MongoDB

### Integrations
* Google OAuth
* YouTube Data API
* Cloudinary

### Automation
* Node-Cron

## Local Setup

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

Ensure environment variables are configured correctly by referencing `.env.example` in both `frontend/` and `backend/` directories.
